## 关于名字

`Nudge` 是行为经济学里的「助推」——不强迫、不打断，只在恰当的时刻轻推一下。
`Bell` 是那一声钟响。合起来就是它做的事：在你走神的那一刻，轻轻推你一下。

中文名「回神」。GitHub 上查过，没有被占用。

## 12 种提示音

全部由程序实时合成，仓库里没有任何音频文件：

| | | |
|---|---|---|
| 水晶铃 | 木鱼 | 水滴 |
| 风铃 | 八音盒 | 颂钵 |
| 电子脉冲 | 林间鸟鸣 | 三角铁 |
| 星尘 | 木琴上行 | 远钟 |

**合成方式**：44.1 kHz / 16 bit 单声道 PCM。每个音色由 2–3 个振荡器（正弦 / 三角 / 方波）叠加，
过一级状态变量滤波器（SVF，可做低通/带通扫频），套指数衰减包络，部分音色叠一层带滤波的
噪声做「木质」或「气声」的质感。生成后整段缓存在内存里，经 winmm `waveOut` 异步播放。

同一个声音听一个月就不再是信号，所以每次随机换一个。设置里单击试听，再单击开关是否参与随机池。

**环境音**三档：雨声（带通噪声 + 随机包络）、棕噪（1/f² 频谱）、低频（周期性低频正弦 +
微弱的拍频）。各自独立音量，随时可关。

## 设置项

| | |
|---|---|
| 盲盒间隔 | 最短 – 最长两根滑杆，1–40 / 2–90 分钟，默认 3–6 |
| 专注周期 | 开关 + 专注时长（5–180 分）+ 休息时长（1–60 分），默认 90 / 20 |
| 音量 / 环境音量 | 独立两条 |
| 心流卡片 | 关掉后只在主窗口弹一条短提示 |
| 系统通知 | 窗口隐藏时用托盘气泡提醒 |
| 窗口置顶 | 压在别的窗口上，摆桌角余光能看到 |
| 响铃时浮到前面 | 关掉卡片时生效，响了自己跳出来 |
| 开机自启 | 写 `HKCU\...\Run` |
| 清空今天的数据 | 只重置今日，历史保留 |

每个数字三套调法：拖滑杆、点左边的 `−`、点右边的 `+`。
改动即时生效，点底部「保存设置」才写进 ini；直接关面板或退出也会替你存下。

**快捷键**：`空格` 开始/暂停，`Esc` 关闭卡片或设置页。

**数据位置**：`%APPDATA%\NudgeBell\state.ini`，纯本地 ini，不联网、不上报、无账号。

## 实现

纯 Win32 + GDI+ 自绘，C++17，静态链接，不依赖 .NET / Qt / Electron / 浏览器内核。

| 部分 | 做法 |
|---|---|
| 界面 | GDI+ 画到离屏位图再 `BitBlt`，运行 30 fps，空闲自动降到 6 fps |
| 无标题栏 | `WM_NCCALCSIZE` 返回 0 削掉非客户区，`WM_NCHITTEST` 把标题区判成 `HTCAPTION` 以支持拖动 |
| 圆角 | Win11 `DwmSetWindowAttribute(DWMWA_WINDOW_CORNER_PREFERENCE)`，必须在 `CreateWindowEx` 之后调用 |
| 浮窗卡片 | 分层窗口：画到 32 位预乘 alpha 的 DIB，再 `UpdateLayeredWindow` 提交。`SetLayeredWindowAttributes` 只能整块统一透明，四角会露黑底，做不出真圆角和羽化阴影 |
| 音效 | 44.1 kHz PCM 实时合成 + `waveOut` 异步播放 |
| 图标 / 托盘 | ico 编进资源，托盘走 `Shell_NotifyIcon` |
| 持久化 | Win32 INI API（`WritePrivateProfileString`） |
| 精度 | `timeBeginPeriod(1)` 把 `WM_TIMER` 拉到 1 ms 粒度，否则刷新率会被系统压到 15.6 ms |

```
src/
├─ main.cpp    窗口、绘制、布局、交互、托盘、持久化
├─ audio.cpp   音色合成引擎 + waveOut 播放
└─ audio.h
res/
├─ app.rc      图标 + manifest
├─ app.ico
└─ app.manifest
build.sh       构建脚本
```

## 构建

需要 MinGW-w64（g++ 11+）：

```bash
./build.sh
```

产物 `NudgeBell.exe`，约 916 KB。脚本会先 `taskkill` 掉正在运行的实例，再重新
`windres` 编资源、`g++` 一次链接出静态可执行文件。

## 自检

不是「编译过了就算」。程序内置两套断言，跑完把结果写成 txt：

```bash
./NudgeBell.exe --selftest   # 逻辑层 12 项
./NudgeBell.exe --autotest   # 界面层 67 项
./NudgeBell.exe --shot       # 导出界面预览图（用 mock 数据）
./NudgeBell.exe --capture    # 真弹一张卡片并抓屏，验证浮窗确实合成到了屏幕上
```

**`--selftest`** 覆盖：12 种音色是否真的合成出有效波形、盲盒 2000 次采样的区间/分布/重复率、
定时模式是否精确等于设定值、时间格式化、ini 往返读写。

**`--autotest`** 覆盖：空闲时是否仍在按时重绘（曾经因为一行调试代码导致只能靠鼠标移动才刷新）、
开始/暂停/恢复、到点自动响铃、浮窗是否真的可见且在屏内、90/20 阶段切换、休息期间不响铃也不计时、
设置页滑杆的鼠标命中、`−/+` 的边界钳制、保存与脏标记。

界面测试发的是真实 `WM_LBUTTONDOWN` 消息，不是直接改 state——之前所有滑杆都被外层背景卡
吞掉点击，正是因为测试绕过了 UI 才一直没发现。

**`--capture`** 是唯一能证明「卡片真的画在屏幕上」的手段：弹一张卡，然后 `BitBlt` 抓桌面那块像素。
窗口 `IsWindowVisible` 为真不代表内容真的合成出来了。

## 为什么不用 Electron

这个软件第一版是 Electron 写的：266 MB，空转 200 MB 内存，一个「偶尔叮一声」的小工具占了半个浏览器。

| | Electron | 现在 |
|---|---|---|
| 体积 | 266 MB | **916 KB** |
| 内存 | 200 MB+ | **22 MB** |
| 启动 | 1–2 秒 | 瞬间 |
| 依赖 | Chromium + Node | 无 |

重写的代价是所有东西都得自己画：没有 CSS，没有布局引擎，连文字换行都要自己按像素量。
好处是启动那一刻就是真的启动完了。
